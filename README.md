# MentalHealth
Website Kesehatan Mental

## Cara Menjalankan (Development)

Jalankan PHP built-in server secara langsung dari folder root:

```bash
php -S localhost:8000
```

Setelah server jalan:
- Halaman utama: http://localhost:8000/index.php
- Admin Login:   http://localhost:8000/admin/login.php (admin / admin123)
- Dashboard Admin: http://localhost:8000/admin/index.php
- Pertama kali, jalankan `php setup_db.php` untuk init database & seed.
